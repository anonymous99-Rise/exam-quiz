## 第 3 轮：内容缺陷 + v3.2–v3.4

**内容级（比观感更伤可信度）**

1. **原文串入试卷说明（162 处）**：`…entrepreneurs and Questions 46 to 50 are based on
   the following passage. scientists…` —— 说明句把句子劈开。
   `tools/scan-passage-bleed.mjs --apply` 全清 + 回归守卫。
2. **7 道选词填空题干被截断**（评审看到的 `34 use the concept of "triage(`）：
   根因是原文中文注音括号切断了句子。2 道从原文自动复位，5 道按**答案词 + 解析语法依据**
   重建（依据写在 tools/fix-cloze-stems-manual.mjs 注释里，未编造词）。校验器加守卫。
3. **音频自持**：7 个 mp3（133MB）→ Supabase Storage 公开桶（MD5 逐一致、Range 206、
   immutable）；2 个 66/68MB 超过 Supabase 免费版单文件上限 → 进仓库由 Vercel 自带
   （`.gitignore`/`.vercelignore` 用 `public/audio/*` + `!` 反排除；vercel.json 给
   `/audio/*` immutable 缓存）。12 套全部有源，且每套都留 CDN 兜底。

**观感**：选词填空页 5443→3757px（词库提到左栏 sticky，不再每题重复）；字母键盘 5×3、
键 50px；手机分段胶囊 288→36px 横滚；0% 进度给文案而非空轨道；年份改真胶囊；
空态补图标；判分加 180ms 轻弹。

## 第 4 轮：设计方向重做（v4「试卷 / Editorial」）

前三轮把**可读性**修好了，但三份独立评审都指向同一结论：**干净、没性格，像「认真写的工具站」**。
于是先出**三个方向的实体 HTML 稿**（`tmp/mockups`：A 试卷编辑风 / B 深色专注 / C 进度游戏化），
让评审对着三张真图排序 —— 结论：**A 的排版最扛得住每天精读 300–400 词英文长文，
C 的进度可视化补它缺的进度感，B 的深色在教室反光、长文精读减分**。

v4 = A 的排版 + C 的进度可视化：

| 层面 | 改动 |
| --- | --- |
| 色彩 | 冷白灰 → **暖纸底 #f7f5f1 + 微暖白面 #fffefb + 暖灰发丝线**；强调色玫粉 → **批改朱红 #9e2b25**（白字 6.4:1），错题色与它同源 |
| 形状 | 圆角 12/16 → 6/8、投影几乎取消；层次改由**细横线与留白**承担 |
| 字体 | 新增 `--font-display`：拉丁数字/日期走衬线（试卷感来源），中文仍无衬线（避免 Windows SimSun 发飘） |
| 列表 | 套卷从「卡片网格」→ **行 + 细横线**（考期 / 规格串 / 进度 / 状态），一屏扫读一整年 |
| 进度 | 单色条 → **按题型分段的 4px 条**（听力/选词/匹配/阅读各一色，宽度按题量、填充按已答）；首页加 **96px 进度环** |
| 题卡 | 细边框无投影；当前题左侧 3px 朱红竖条；选项去边框改细横线分隔行，判分用左侧竖条 + 浅底；字母改**圆形圈号** |
| 解析 | 一整块 3px 朱红左竖线 + 大写间距小标签（不再一排彩色胶囊） |
| 导航 | 品牌方角墨块；当前栏墨字 + 2px 朱红下划线 |

## 沉淀的两个工具坑（下次直接省一小时）

1. **`.gitignore` 反排除必须先放开父目录**：`public/audio/`（目录）一旦被排除，
   后面对其子文件的 `!` 无效；要写成 `public/audio/*` + `!public/audio/<file>`。
2. **Vercel 部署 Error 且 build 日志为空** → 是 `vercel.json` schema 校验失败，
   真正的错误只在 REST API 里：`GET https://api.vercel.com/v13/deployments/<id>`
   的 `errorMessage` 字段（`vercel logs` 只说「never reached READY」）。
